## 你以前会怎么做？

买了团购之后、出发之前，你也想先了解一下情况。

**去某书搜一搜。** 可打开一看：
- 搜出来的帖子——一半是广告，一半是软文推广
- 好不容易找到一条真实的——发布时间是**三个月前**
- 你也想发帖问"现在人多吗"——但谁会刚好看到并回复你？

**三个月前人不多，不代表今天人不多。某书博主说好，不代表真的好。**

## 实时探路是什么？

一句话概括：**花几块钱，让已经在那里的人帮你看一眼。**

跟去某书发帖搜帖不同——实时探路通过 **GPS定位** 保证回答者确实在现场，而且是**现在**。

### 与美团的结合点

- **痛点源自团购**：买了景点门票、餐厅团购、酒店预订后，最担心"实际跟预期不符"
- **补全消费决策**：美团解决了"去哪里、多少钱"，实时探路解决"现在去值不值"
- **提升消费体验**：减少"到了才失望"的情况
- **天然用户匹配**：美团的海量线下消费用户，天然就是"正在那个地方的人"

### 核心流程

```
① 发布任务 → ② 附近推送 → ③ 接单前往 → ④ 拍照提交 → ⑤ 确认收货 → ⑥ 赏金到账
```

### 关键规则

| 机制 | 说明 |
|------|------|
| GPS定位校验 | 接单和提交时，设备定位需在任务地点 **1000米** 范围内 |
| 资金托管 | 发布任务时悬赏金预冻结，确认后才发放给接单者 |
| 最低悬赏 | **0.01元** 起 |
| 时效保护 | 任务过期自动关闭并退款 |
| 自动确认 | 提交后24小时未操作自动确认支付 |
| 实时聊天 | 发布者可追加问题，接单者实时回复 |
| 双向评价 | 任务完成后双方互评 |
